# Балістична варта Києва (Android)

Додатковий звуковий сигнал на повідомлення Telegram-каналу (за замовчуванням
«Київське небо») про **балістику** та **цілі на Київ**. Застосунок читає лише
сповіщення Telegram **на самому телефоні**: без входу в Telegram, без API-ключів,
без дозволу на інтернет.

> ⚠️ Це не заміна офіційної повітряної тривоги. Будь-який збій (Telegram не
> надіслав сповіщення, Android «приспав» застосунок, канал змінив формулювання)
> означає пропущений сигнал.

## Статус

| Частина | Стан |
|---|---|
| Логіка розпізнавання повідомлень (`AlertClassifier`) + 9 unit-тестів, зокрема реальна послідовність повідомлень каналу | 🟢 перевірено тестами |
| Збірка й підпис APK (`scripts/build-apk.sh`) | 🟢 збирається, `apksigner verify` проходить |
| Збірка через Android Studio / Gradle (AGP 8.7, `compileSdk 35`) | 🟡 налаштовано, перевіряється GitHub Actions |
| Робота на реальному телефоні (вимкнений екран, «Не турбувати», Samsung battery) | 🟡 ще не перевірено на пристрої |
| Читання відредагованих повідомлень (Telegram не надсилає сповіщень про редагування) | 🔵 неможливо цим способом |

## Як працює

1. `AlertListenerService` (NotificationListenerService) отримує сповіщення від
   Telegram і бере лише ті, у заголовку яких є назва каналу.
2. `AlertClassifier` класифікує кожне нове повідомлення:
   * **Відбій** («відбій», «загроза минула») → вимикає сигнал, закриває вікно уваги.
   * **Загроза балістики** («балістика», «виходи», «пуск», «Іскандер», «Кинджал»…)
     → сигнал, відкриває вікно уваги (15 хв, налаштовується).
   * **Ціль на Київ**: у вікні уваги — «Київ/Києв/столиц» (налаштовується) або
     «ціль», «падають», «фіксація», «летять» → сильніший сигнал, вікно подовжується.
     Якщо «балістика» і «Київ» в одному повідомленні — одразу сильний сигнал.
   * Решта («Поки все», «Працює ППО») ігнорується.
3. `AlarmPlayer` грає мелодію будильника через потік **ALARM** (його «Не турбувати»
   зазвичай пропускає), вібрує й показує сповіщення з кнопкою «Зупинити звук».

Перевірка на повідомленнях із каналу (ніч, коли зроблено скриншот):

| Час | Повідомлення | Реакція |
|---|---|---|
| 01:56 | Відбій по балістиці | ✅ відбій |
| 03:00 | Загроза балістики з Брянська | ⚠️ сигнал |
| 03:02 | Працює вороже ППО… | — |
| 03:03 | Є ціль / На Київ / 2 цілі | 🚀 сильний сигнал |
| 03:27 | Можливо відбулися ще виходи, увага | ⚠️ сигнал |
| 03:28–03:30 | Ціль / 2 цілі на Київ / Падають / Фіксація прямо перед Києвом / Ще 2 цілі / В бік Північного мосту летять | 🚀 сильний сигнал |
| 03:31 | Поки все | — |

Однаковий сигнал не перезапускається частіше ніж раз на 20 с.

## Встановлення та налаштування (Samsung, Android 13–15)

1. Встановіть APK (дозвольте встановлення з цього джерела).
2. **Telegram → канал → увімкніть сповіщення.** Якщо канал заглушено, Telegram
   нічого не показує й застосунок нічого не побачить. Звук Telegram для каналу
   можна вимкнути — достатньо, щоб сповіщення з'являлося.
   **Також: Telegram → Налаштування → Сповіщення → «Попередній перегляд
   повідомлень» має бути увімкнено.** Інакше в сповіщенні лише «Нове
   повідомлення» без тексту, і аналізувати нічого.
3. Відкрийте «Балістична варта» → **Доступ до сповіщень** → увімкніть.
   Якщо перемикач сірий: *Налаштування → Програми → Балістична варта → ⋮ →
   «Дозволити обмежені налаштування»* і повторіть (обмеження Android 13+ для
   застосунків не з Play Market).
4. **Дозволити показ сповіщень** (Android 13+).
5. **Не обмежувати роботу у фоні** — також на Samsung: *Налаштування → Батарея →
   Обмеження фонового використання* — переконайтеся, що застосунку немає в списку
   «сплячих».
6. «Не турбувати»: переконайтеся, що **будильники** дозволені (так за замовчуванням).
7. Натисніть **«Тест: ціль на Київ»** — має пролунати будильник. Потім перевірте
   з вимкненим екраном, надіславши собі тестове повідомлення в канал/групу з такою
   ж назвою.

## Збірка

**Android Studio:** відкрийте теку репозиторію, `Run ▶`. Або `./gradlew assembleDebug`.

**Без Android SDK** (Ubuntu/Debian; так зібрано APK у цьому репозиторії):
див. коментар на початку `scripts/build-apk.sh`, потім `scripts/build-apk.sh`.

Усі збірки підписуються одним ключем `keystore/debug.jks` (пароль `android`),
щоб нову версію можна було встановити поверх старої. Ключ публічний — він не
підходить для публікації в магазині.

## Приватність

* Обробляються лише сповіщення клієнтів Telegram, у заголовку яких є назва каналу.
* Дозволу на інтернет немає — текст фізично не може бути відправлений.
* Журнал у застосунку зберігає **лише повідомлення, що спричинили сигнал**
  (до 40 рядків, локально, кнопка «Очистити журнал»). Решта тексту не зберігається.
* Не потрібні пароль Telegram, SMS-код, API Hash чи файл сесії.

## Обмеження

* Telegram не надсилає сповіщень про **редагування** повідомлень — якщо канал
  дописує інформацію в старий пост, застосунок цього не побачить.
* Залежить від формулювань каналу. Інший канал може потребувати інших слів
  (налаштування «Слова "Київ"» та код `AlertClassifier`).
* Підтримувані клієнти: офіційний Telegram (Play/APK/beta), Telegram X, Plus,
  Nekogram, exteraGram, Cherrygram.
